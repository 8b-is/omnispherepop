Weight programming for humans and agents

Turn a weight matrix into three symbols.
Keep the behaviour. Lose the bytes.

Omnispherepop treats weights as a program: quantize to {-1, 0, +1}, diff two snapshots with a reversible receipt, prune across ultra-edges, and let an agent drive the same operations over MCP.

Run the sandboxcargo install






  
Live ternary sandbox

  
Real quantization of a 512-value tensor, computed in your browser with the same rule as the Rust kernel.
